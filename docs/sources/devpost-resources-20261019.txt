New to YouCam API? Get up and running in under 30 minutes with these resources. Whether you're making your first API call or picking the right endpoint for your project, these guides will fast-track your understanding of the platform.
Quick Start in 3 Steps:
Register on Devpost. Get your exclusive redeem code by email (2 minutes)
Sign up for YouCam API. [https://yce.perfectcorp.com/ai-api?utm_source=event&utm_medium=YouCamAPIHackathon&utm_campaign=devpost&utm_content=skin_ecommerce] Click here to sign up and verify your email. (2 minutes)
Claim Your Free 1,000 YouCam API Units. [https://yce.perfectcorp.com/ai-api?utm_source=event&utm_medium=YouCamAPIHackathon&utm_campaign=devpost&utm_content=skin_ecommerce] Click here and go to Account > Redeem Code > Enter the redeem code (3 minutes)
For India region, please click [https://www.makeupar.com/perfectbeauty/youcam/terms-of-service-api?utm_source=event&utm_medium=YouCamAPIHackathon&utm_campaign=devpost&utm_content=skin_ecommerce] HERE
1,000 API Units will be added to your account immediately.
Pick an API, review the project ideas below, and start building. You can have your first request running in about 30 minutes.
API Type: Standard RESTful API
Works with websites, e-commerce platforms, iOS/Android apps, and mini-programs. No special SDK required.
